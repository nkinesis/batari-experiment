# Godzilla base game

Batari BASIC base game by Gabriel C. Ullmann, 2026.

## Instructions

- In VS Code, install Atari Dev studio
- Open source code file (\*.78b)
- Click the rocket icon on the bottom of the screen to compile and launch (or press F5)
- Once the emulator window is open, you can press Tab to access settings. For example, for this game I changed my screen width to 530.
